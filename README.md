# 🎮 GTA VI – Landing Page Concept

A GTA VI-inspired landing page created using **HTML and CSS**. This project recreates a cinematic Grand Theft Auto VI promotional-style webpage inspired by Rockstar Games.

## 🌆 Project Preview

The landing page features a dark cinematic background, bold typography, navigation menu, and interactive hover effects to create a GTA VI-inspired experience.

## ✨ Features

- **Navigation Bar:** A simple navigation menu featuring Home, Start, Media, and Explore.
- **Cinematic Background:** Full-screen GTA VI-inspired background image with dark gradient overlays.
- **Bold Typography:** Large and eye-catching text displaying GRAND THEFT AUTO VI.
- **Interactive Hover Effects:** Animated side boxes that expand when hovered over.
- **Explore Button:** A styled call-to-action button with hover animations.
- **Smooth Transitions:** CSS transitions and transform effects for interactive elements.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 CSS Concepts Practiced

This project helped me practice and understand:

- CSS Grid
- Flexbox
- Positioning (Absolute and Relative)
- Background Images and Gradients
- Margins and Padding
- Typography and Font Styling
- Hover Effects (`:hover`)
- CSS Transitions
- CSS Transforms (`scaleX()` and `translateX()`)
- Zoning and Layout Management
